# 해음위키 업데이트 안내

## v2.5 업데이트

### 테마 선택
- 화이트 테마, 다크 테마, 해음위키 전용 테마 중 원하는 화면을 선택할 수 있습니다.
- 선택한 테마는 저장되어 다음에 방문할 때도 유지됩니다.

### 모바일 최적화
- 모바일 화면에 맞게 상단 메뉴와 로고, 검색 영역을 정리했습니다.
- 테마 전환과 메뉴를 작은 화면에서도 편하게 사용할 수 있도록 개선했습니다.
- 프로필과 통계 정보, 타임라인 및 표의 모바일 가독성을 개선했습니다.
- 이미지 크기와 화면 여백을 조정해 모바일 웹에서 더 자연스럽게 표시되도록 했습니다.
