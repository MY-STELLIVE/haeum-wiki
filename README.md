# 해음위키 v2.7.0 업데이트

## 이번 업데이트
- 프로필 문서의 정보·소개·목차·본문을 순서대로 읽을 수 있도록 재정렬했습니다.
- 모바일 웹에서 서술 본문과 하위 문서 카드를 세로 1열로 표시합니다.
- 방송 통계 요약과 상세 기록의 간격 및 반응형 배치를 정리했습니다.
- 긴 표는 글자 크기를 과도하게 줄이지 않고 좌우 스크롤로 확인하도록 유지했습니다.
- 기존 문서 내용, 통계 수치, 이미지 및 테마 기능은 유지했습니다.

## 적용 방법
1. 저장소 최상위의 `index.html`을 교체합니다.
2. `assets/css/` 폴더에 `document-layout.css`를 추가합니다.
3. 변경 사항을 Commit 합니다.

`document-layout.css`는 기존 CSS 뒤에 추가로 불러오므로 기존 스타일 파일을 삭제하거나 이름을 바꾸지 마세요.
